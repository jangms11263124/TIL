### 프로젝트 제작 동기

1. 금융 데이터를 효율적으로 관리하고 사용자 간의 의견을 실시간으로 나누는 공간을 제공하기 위해 시작했습니다.
2. Django 프레임워크를 활용하여 안정적이고 보안이 강화된 웹 애플리케이션 구축 역량을 쌓고자 했습니다.
3. OpenAI API를 연동하여 복잡한 금융 뉴스를 자동으로 요약하고 사용자에게 핵심 정보를 제공하고 싶었습니다.
4. 토스(Toss) 스타일의 직관적이고 미니멀한 UI를 직접 구현하여 사용자 경험(UX)을 극대화하고자 했습니다.
5. 단순한 게시판 기능을 넘어 실제 금융 도메인 지식을 기술로 풀어내는 과정을 경험하기 위한 목적입니다.

### 프로젝트 소감

1. Django의 MVT 패턴을 따라 웹 서비스의 전체적인 아키텍처를 직접 설계하며 백엔드 기술의 기반을 다졌습니다.
2. 외부 뉴스 데이터를 크롤링하고 AI로 가공하여 DB에 저장하는 파이프라인을 구축하며 데이터 처리의 즐거움을 느꼈습니다.
3. CSS를 활용해 깔끔한 UI를 만드는 과정에서 디자인 감각과 프론트엔드 역량의 중요성을 다시 한번 깨달았습니다.
4. 프로젝트를 진행하며 마주한 다양한 에러들을 해결하며 코드의 견고함과 예외 처리의 필요성을 깊이 이해하게 되었습니다.
5. 금융 모델링과 추천 시스템의 가능성을 확인하며, 향후 더욱 고도화된 핀테크 서비스를 만들고 싶다는 확신을 얻었습니다.
