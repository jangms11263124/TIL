# SSAFY 15기 관통 프로젝트

**단계별 학습 내용**

- 1단계: api를 api 키를 활용하여 날씨 정보를 불러올 수 있다는 것을 배웠습니다.
- 2단계: 1단계에서 불러온 값 중 특정 값만을 추출하는 방법을 배웠습니다.
- 3단계: 2단계에서 추출한 값을 한국어로 변환하는 방법을 배웠습니다.
- 4단계: 2단계에서 불러온 값 중 온도 값을 기본 켈빈에서 섭씨로 바꾸는 방법을 배웠습니다.



**어려웠던 부분**

    3단계부터는 아직 배우지 못한 내용이 나와서 조금 당황했습니다. 다음주 수업자료를 참고하여 구현하느라 시간이 오래 걸렸습니다.기존에 배웠던 내용도 막상 코드로 작성하려고 하니까 기억이 잘 나지않아 배운 내용을 직접 작성하는 연습을 더 해야겠다고 느꼈습니다. 그리고 자료형 중에서 딕셔너리랑 리스트가 정말 많이 사용되고 잘 쓰는 것이 중요하다고 생각하였습니다. 또한 단계가 올라갈수록 추가되는 내용이 많아서 코드를 깔끔하고 명시적으로  작성하는데 어려움을 느꼈습니다. 그리고 중간중간 주석이 잘못된 부분이 있어서 그대로 작성하려고하기보다 문제와 결과값을 잘 이해하고 시작하는 것이 중요하다는 것을 느꼈습니다. API값을 계속 요청하면서 그 안에서 필요한 자료를 찾고 필요한 부분을 수정하여 원하는 값을 얻을 수 있다는 것이 인상깊었습니다.
