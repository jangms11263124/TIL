# 🎬 Netflix Stock Price Data Analysis Project

파이썬과 주피터 노트북을 활용하여 넷플릭스(NFLX)의 과거 주가 데이터를 분석하고, 다양한 지표를 시각화하여 인사이트를 도출하는 프로젝트입니다.

## 🎯 1. 프로젝트 목표

- **데이터 분석 프로세스 이해:** 수집, 전처리, 분석, 시각화로 이어지는 전체 흐름을 파악합니다.

- **데이터 전처리 역량 강화:** `pandas`와 `numpy`를 활용해 요구사항에 맞게 데이터를 가공합니다.

- **시각화 실전 적용:** `matplotlib`을 통해 복잡한 수치 데이터를 직관적인 그래프로 표현합니다.

- **AI 인사이트 도출:** 생성형 AI를 활용하여 데이터 기반의 주가 예측 및 시장 분석을 수행합니다.

## 🛠 2. 기술 스택 및 라이브러리

- **Language:** Python

- **Environment:** Jupyter Notebook

- **Libraries:**
  
  - `pandas`: 데이터 로드 및 전처리
  
  - `numpy`: 수치 연산 처리
  
  - `matplotlib`: 데이터 시각화
  
  - `csv`: CSV 파일 핸들링

## 📋 3. 주요 분석 단계 및 기능

### 1️⃣ 데이터 수집 (Data Collection)

- Kaggle에서 제공되는 넷플릭스 주가 데이터(`NFLX.csv`)를 로드합니다.

### 2️⃣ 데이터 전처리 (Data Preprocessing)

- `Date`부터 `Close`까지 분석에 필요한 핵심 컬럼을 선별합니다.

- 문자열 형식의 날짜 데이터를 `datetime` 객체로 변환하여 분석 효율을 높입니다.

### 3️⃣ 시각화 및 분석 (Visualization & Analysis)

- **2021년 이후 종가 추이:** 코로나19 이후 넷플릭스 주가의 전반적인 흐름을 라인 그래프로 시각화합니다.

- **최고/최저가 추출:** 특정 기간 내의 `Close` 기준 최고가와 최저가를 계산합니다.

- **월별 평균 종가 분석:** 일별 변동성을 제거하고 월 단위 평균을 내어 장기적 추세를 확인합니다.

- **2022년 이후 복합 지표 시각화:** High(고가), Low(저가), Close(종가)를 한 그래프에 표시하여 주가 변동 폭을 분석합니다.

### 4️⃣ AI 기반 인사이트 (AI Insights)

- 생성형 AI 프롬프트를 통해 분석된 데이터를 바탕으로 향후 주가 전망 및 매수/매도 전략에 대한 AI의 의견을 도출합니다.
