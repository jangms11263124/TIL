# SSAFY 15기 관통 프로젝트

- 단계별 학습 내용
  
  1. Kaggle에서 원하는 데이터를 다운로드하는 방법을 배웠습니다.
  
  2. 다운받은 데이터를 CSV 파일로 읽어오고, numpy, pandas, matplotlib을 사용하여 필요한 칼럼만 선별해서 불러오는 방법을 배웠습니다.
  
  3. 특정 시기 이후의 데이터만 필터링 한 후 matplotlib을 이용하여 시각적인 그래프로 나타내는 방법을 배웠습니다.
  
  4. 특정 데이터 값만 추출하는 방법을 배웠습니다.
  
  5. groupby를 이용하여 데이터를 그룹화하는 방법을 배웠고, x축을 45도 돌린다거나 2달 간격으로 나타나게 하는 방법을 배웠습니다.
  
  6. 데이터를 필터링하여 3가지 데이터를 한번에 그래프로 표현하는 방법을 배웠고, 범례를 추가하는 방법도 배웠습니다.
  
  7. 심화 1) 생성형 ai를 통해 앞으로의 주가 전망과 매도/매수 판단을 부탁했습니다.

- 느낀 점
  
  5단계에서 월별 데이터를 통합하는 함수가 조금 어려웠습니다. 강사님과 생성형  ai를 통해 학습 후 진행하였습니다. 나머지는 제공해주신 자료가 너무 좋아서 하나하나 따라서 진행하니까 수월하였습니다. 코드를 이용해서 항상 출력값만 보다가 실제로 그래프와 같이 시각적으로 결과값을 볼 수 있어서 배움의 영역이 확장된것 같습니다.  지난시간에 외부 데이터를 받아오는 것을 배웠고 이제 그 데이터를 가지고 조작하는 방법을 배워서 앞으로 뭘 더 할 수 있을지 기대됩니다.
