# PJT08 - 은행 검색 애플리케이션 (금융 상품 비교 애플리케이션 10회차)

본 프로젝트는 **Kakao Map API**를 활용하여 사용자가 원하는 지역과 은행을 드롭다운을 통해 선택하면, 해당 위치 내에 존재하는 은행 지점들을 지도상에 시각화해 주는 지도 기반 웹 페이지 구현 프로젝트입니다. 순수 HTML, CSS, JavaScript(바닐라 JS)만을 이용한 프론트엔드 중심의 API 연동 서비스입니다.

---

## 1. 프로젝트 개요 및 구조

```text
금융/

│   └── data.json           # [제공됨] 전체 행정구역 및 은행명 raw 데이터

└── style.css               # 삼성 블루 테마를 반영한 현대적이고 세련된 CSS
```

## 2. 주요 기능 및 요구사항 충족 현황

### 💡 기능적 요구사항 (Functional Requirements)

1. **Kakao 지도 API 등록 및 발급 (F1001)**
   - Kakao Developers 애플리케이션 등록 후 JavaScript Key 발급 완료.
   - 로컬 실행 주소(`http://127.0.0.1:5500`)를 Web 플랫폼에 올바르게 연동할 수 있도록 안내 설계.

2. **지도 출력 기능 (F1002)**
   - Kakao Map SDK를 동적으로 임포트하여 화면 우측에 지도를 출력합니다.
   - 초기 중심 좌표는 요구사항 명세에 따라 **강남역(위도: 37.49818, 경도: 127.027386)**으로 정밀 설정했습니다.
   - 사용자 편의를 위해 지도 타입 컨트롤(지도/스카이뷰) 및 줌 컨트롤을 추가 제공합니다.

3. **은행 검색 UI 구성 및 3단계 동적 드롭다운 (F1003)**
   - `data.js` 내에 정의된 데이터를 연동하여 `광역시/도` ➔ `시/군/구` ➔ `은행명`이 단계별로 연동되는 **3단계 드롭다운**을 구현했습니다.
   - 각 Select Box의 `change` 이벤트를 리스닝하여 이전 단계가 선택되기 전에는 다음 단계가 비활성화(`disabled`) 및 기본값으로 자동 초기화되도록 세밀하게 설계했습니다.

4. **은행 검색 및 마커/인포윈도우 표시 (F1004)**
   - 3단계 조건이 모두 채워진 후 '찾기' 버튼을 누르면, `${광역시/도} ${시/군/구} ${은행명}` 형태로 키워드 문자열을 동적 생성합니다.
   - Kakao Maps `Services` 라이브러리의 `Places` 객체를 통해 키워드 검색을 수행합니다.
   - 검색 성공 시 기존 마커 및 인포윈도우를 깨끗하게 지워(중복 표시 방지) 리소스를 최적화합니다.
   - **[정밀 필터링 적용]** 검색 결과 목록 중 현재 사용자가 명시적으로 선택한 `시/군/구` 이름이 주소지에 부합하는 지점만 선별하여 마커를 그립니다. 이를 통해 타 지역(인접 구 등)의 지점들 때문에 지도가 광광역시/도 수준으로 광범위하게 줌 아웃되는 문제를 방지하고, 지정된 구역에 완벽히 포커싱되도록 조절했습니다.
   - 검색된 모든 지점의 좌표를 포함하도록 지도의 영역 경계(`LatLngBounds`)를 자동으로 재설정하여 화면에 모든 지점이 한눈에 들어오게 조절합니다. (단일 지점 검출 시에는 수준 높은 시인성을 위해 레벨 4로 세밀 줌인 제어하며, 다수 지점 역시 극단적 근거리 분포 시 줌인 오버를 방지하기 위해 최소 레벨 4 이상을 유지합니다.)
   - 마커 클릭 시 Custom CSS가 가미된 세련된 인포윈도우(`InfoWindow`)를 띄워 **은행 지점 이름**과 **상세 도로명(혹은 지번) 주소**를 가독성 있게 출력합니다.

## 3. 비기능적 요구사항 및 디자인 아키텍처

- **로컬 서버 실행 환경 (NF1001)**: VSCode Live Server 확장 프로그램을 통해 로컬 환경 포트 5500에서 완벽하게 동작합니다.
- **보안성 극대화 (NF1002)**: API Key를 전역 스크립트인 `apikey.js`에 격리 수용하고, `.gitignore`를 통해 Git Repository 등에 키가 유출되는 사고를 원천 차단했습니다.
- **코드 구조화 (NF1003)**: HTML(구조), CSS(스타일), JS(동작/로직)를 명확히 분리하여 웹 표준과 관심사 분리(SoC) 원칙을 준수했습니다.
- **직관적인 UI 가독성 (NF1005)**:
  - **삼성 시그니처 블루(#034EA2) 테마**가 적용된 세련된 헤더와 화면 좌측의 카드형 사이드바(Sidebar), 그리고 우측의 시원한 지도가 황금 비율로 스플릿 배치되었습니다.
  - 브라우저 기본 드롭다운의 밋밋함을 없애기 위해 커스텀 Chevron 아이콘, 부드러운 포커스 아웃라인 애니메이션을 적용했습니다.
  - API Key가 정상적으로 설정되지 않았을 경우, 지도 화면 위에 블러 처리된 아름다운 Warning Glassmorphism 카드 레이어를 띄워 사용자가 키 입력을 해야 함을 직관적으로 인지하도록 가이드합니다.

## 4. 구현 과정에서의 학습 내용

1. **카카오 지도 API의 비동기 동적 로딩 구현**
   - HTML 내에서 `<script src="...">`로 API 키를 하드코딩하지 않고, `apikey.js`에서 불러온 변수(`API_KEY`)를 바탕으로 동적 `<script>` 요소를 생성하고 로드하는 방식을 학습하고 실적용했습니다.
   - SDK 로드 완료 시점을 파악하기 위해 `&autoload=false` 파라미터를 추가하고 `kakao.maps.load()` 콜백 안에서 지도를 초기화하는 구조적 제어를 구현했습니다.
2. **이벤트 드리븐 방식의 cascading 드롭다운 구조 설계**
   - 하위 드롭다운이 상위 드롭다운의 `value` 변화에 의존적이므로 이벤트 전파와 `disabled` 속성의 제어 타이밍이 중요함을 배웠습니다. `change` 리스너 내부에서 상태 초기화 함수(`resetSelect`)를 공통 모듈화하여 유연하게 대처했습니다.
3. **지도 뷰포트의 경계 설정(Bounds Management)**
   - 검색된 마커들의 좌표 목록을 순회하며 `kakao.maps.LatLngBounds` 객체에 `extend()`로 누적한 뒤, 최종적으로 `map.setBounds(bounds)`를 호출하여 자동으로 지도 줌 레벨과 중심점을 맞추는 동적 뷰포트 핸들링 기술을 마스터했습니다.

## 5. 어려웠던 점 및 해결 방법

- **어려웠던 점 (CORS 이슈 및 API 키 보안 관리)**:
  - 원래 브라우저 단에서 로컬의 `data.json`을 직접 `fetch`해 오려고 할 때 로컬 보안 정책이나 CORS 환경 문제로 인해 오류가 발생할 우려가 있었습니다.
  - **해결 방법**: `data.json`의 원본 JSON 형식을 정적 자바스크립트 파일인 `data.js` 내에 `const BANK_DATA = { ... }` 전역 객체 변수로 래핑하여 import 하도록 함으로써, 서버 환경 제약 없이 프론트엔드가 데이터를 안전하고 빠르게 즉시 사용할 수 있도록 구조화했습니다.
- **어려웠던 점 (기본 인포윈도우의 투박한 스타일링)**:
  - 카카오 지도 API가 기본으로 제공하는 `InfoWindow`는 폰트가 투박하고 내부 패딩 및 보더 디자인이 다소 노후하여, 고품격 UI 디자인 콘셉트에 맞지 않았습니다.
  - **해결 방법**: 인포윈도우에 주입되는 마크업 콘텐츠에 `info-window-card`, `info-window-title`, `info-window-address`와 같은 명확한 클래스를 할당하고, `style.css`에서 해당 클래스들을 상대로 디테일한 타이포그래피 설정, 패딩, 테두리 둥글기, 그리고 오렌지 테마 배지를 추가 부여하여 일관되고 매끄러운 룩앤필을 구현했습니다.

## 6. 프로젝트 완료 소감 및 반성

순수 바닐라 자바스크립트만으로도 상태 관리와 비동기 API 통신, 그리고 세련된 인터랙션을 충분히 조화롭게 조율할 수 있음을 체감한 뜻깊은 프로젝트였습니다. 평소 프레임워크에만 의존하던 3단계 선택 박스의 바인딩 로직을 브라우저 네이티브 이벤트 핸들링으로 직접 바닥부터 짜 보면서 JS 핵심 매커니즘에 대한 이해도를 크게 높일 수 있었습니다.

추후 프로젝트 진행 시에는 더 확장된 카카오 모빌리티 길찾기(Driving API) 등의 심화 기능을 추가 접목하여, 금융 지점 검색부터 직접 방문하는 이동 경로까지 실시간 안내해 주는 통합 금융 서비스 허브로 확장해 보고 싶습니다.
