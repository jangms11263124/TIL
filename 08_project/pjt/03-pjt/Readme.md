# 한승민
## 금융 상품 비교 애플리케이션 - 반응형 Profile 페이지 구현

## 1. 프로젝트 개요
* **프로젝트명:** 반응형 Profile 페이지 구현
* **주제:** 금융 상품 비교 애플리케이션의 사용자 프로필 및 포트폴리오 수정 페이지 제작
* **개발 환경 (Tech Stack):**  HTML5
  * CSS3
  * Bootstrap 5.3
  * Vanilla JavaScript (금액 단위 포매팅 및 슬라이더 동적 제어)

## 2. 프로젝트 목표
* HTML, CSS의 동작 원리를 이해하고 예시 화면을 구현한다.
* Bootstrap과 CSS를 활용하여 본인만의 프로필 페이지를 구현한다.
* Media Query 등 핵심 기술을 활용하여 다양한 화면 크기에 대응하는 반응형 UI를 구성한다.


## 3. 핵심 기능 및 요구사항 구현 (F301 ~ F305)

### F301: 프로필 및 투자 성향 출력
* **프로필 사진:** 원 모양으로 출력하고 그림자(`box-shadow`) 속성을 활용하여 입체감을 부여했습니다. (본인 커스텀 사진인 `dong.png` 적용)
* **자기소개:** Textarea와 button을 활용하여 하단에 배치했습니다.
* **투자 성향:** 여러 선택지를 다중 선택 또는 단일 선택할 수 있도록 UI를 구성했습니다.

### F302: 기본 정보 수정 페이지 구현
* **회원 정보 출력:** 회원 번호, ID, Email, Nickname, 나이, 자산과 연봉 등을 폼(Form) 형태로 출력합니다.
* **수정 가능한 UI:** 편집할 수 없는 필드(회원 번호, ID)는 `readonly`로 처리하고, 나이와 자산/연봉은 각각 데이터 형태에 맞는 input 속성을 적용했습니다.

### F303: 네비게이션 바 구현
* 화면 상단에 다른 페이지로 이동 가능한 네비게이션 바를 구현했습니다.
* 탭(Tab) 형식을 활용하여 '프로필 수정'과 '포트폴리오 수정' 페이지 간 화면 새로고침 없이 매끄러운 전환이 가능하도록 구성했습니다.

### F304: 포트폴리오 수정 페이지 구현
* 회원의 금융 포트폴리오 정보(회원 번호, ID, 저축 성향, 최애 은행)를 출력하도록 구성했습니다.
* 저축 성향은 라디오 버튼으로, 최애 은행 등은 다중 선택 체크박스로 고도화하여 구현했습니다.

### F305: 반응형 디자인 구현
* Bootstrap의 Grid 시스템과 Media Query를 활용하여 반응형 레이아웃을 구성했습니다.
* 가로 사이즈 768px 미만(모바일 환경) 시 우측 패널의 상단 여백이 자연스럽게 조정되며, 콘텐츠가 수직으로 깔끔하게 재배치되도록 설계했습니다.


## 4. 커스텀 및 심화 구현 사항 (기획 변경점)
명세서의 기본 요구사항을 바탕으로, 실제 서비스에 더 적합하고 유머러스한 디테일을 추가하여 프로젝트를 고도화했습니다.

1. **전체 UI 테마 및 컨셉 변경**
   * 트렌디한 금융 앱 느낌을 주기 위해 Bootstrap 5의 `data-bs-theme="dark"` 및 커스텀 CSS를 활용하여 **전체 다크모드**를 적용했습니다.
   * 네이밍을 "업계 큰손님의 프로필 페이지"로 변경하고, "한국의 일론 머스크를 꿈꾸는 김동언입니다."라는 위트 있는 자기소개를 기본값으로 설정하여 프로젝트의 개성을 살렸습니다.

2. **디테일한 폼(Form) 요소 개선**
   * **이메일 입력 고도화:** 이메일 아이디 입력창 옆에 도메인 선택을 위한 `select` 박스를 추가했습니다. (직접입력, @naver.com, @gmail.com 등)
   * **결혼 및 주거 형태 분리:** 기존 통합된 항목을 분리하여, 주거 형태(전세, 월세, 자가, 기숙사/본가)를 세밀하게 선택할 수 있게 했습니다.
   * **직업군 세분화:** 단순 학생/직장인을 넘어 9가지(취업준비생, 주부, 프리랜서, 개인사업자 등)로 선택지를 확장했습니다.

3. **자바스크립트(JS)를 활용한 동적 포매팅 (이스터에그 추가)**
   * 자산 및 연봉 입력을 `range` 슬라이더로 구현하고, 실시간으로 **'조/억/만 원' 단위로 변환**되도록 했습니다.
   * **자산 슬라이더:** 100만 원 단위로 조절되며, 한계치 도달 시 "1,245조 원 (일론 머스크)"라는 텍스트가 출력되도록 이스터에그를 넣었습니다.
   * **연봉 슬라이더:** 최대치 도달 시 "10억 이상"으로 텍스트가 변경됩니다.

4. **사용자 경험(UX) 개선**
   * 선호 자산군 및 관심 산업, 금융사 선택 시 **글자(Label)를 클릭해도 체크박스가 작동**하도록 `id`와 `for` 속성을 매핑하여 접근성을 높였습니다.
   * '최애 은행' 항목을 '주거래 은행'과 '선호 금융사(증권/보험)'로 세분화하여 다중 선택 체크박스 리스트로 고도화했습니다.


## 5. 학습 내용 및 트러블 슈팅 (NF301)

* **해결 방법 및 배운 점:** Vanilla JavaScript를 활용하여 `input` 이벤트 리스너를 달고, `Math.floor`와 나머지 연산자(`%`)를 활용해 실시간으로 숫자를 '조/억/만 원' 단위로 포매팅하는 커스텀 함수(`formatKoreanCurrency`)를 직접 구현했습니다. 이를 통해 DOM 조작과 이벤트 처리의 작동 원리를 체득할 수 있었습니다.
* **느낀 점:** Bootstrap의 Grid 시스템(`col-md-6` 등)과 탭 컴포넌트(`data-bs-toggle="pill"`)를 활용하니 복잡한 레이아웃과 화면 전환을 쉽고 빠르게 구현할 수 있었습니다. 또한, `label`의 `for` 속성을 활용해 텍스트 클릭 시 체크박스가 연동되도록 하는 등 작은 UX 디테일이 완성도를 크게 높인다는 것을 깨달았습니다.

# 장민석

#### 프로젝트 후기 및 느낀 점

부트 스트랩을 활용하니 다양한 디자인을 생각보다 쉽게 구현할 수 있었습니다.
전반적으로 요즘 스타일과 달라 원하는 스타일과 내용을 파트너와 먼저 구성하고 구성안을 가지고 작업을 진행하였습니다.
원하는 파트를 구현하기 위해 부트 스트랩 사이트나 mdn을 찾는데 ai를 활용하여 진행하였습니다.
다만 아직까지 선택 바를 움직이는 것처럼 작동하는 것은 배우지 못하여서 익숙하지 않았습니다.
그리고 아직 자바 스크립트를 배우지 않아 실제로 저장이나 업데이트는 되지 않는데 그것도 되면 좋을 것 같습니다.
