프로젝트 기능 구현 상세 

F 501: 기본 유저 대신 커스텀 유저 모델을 만든 후 필드에 여러가지 정보를 추가하고, 프로필 이미지의 경우 이미지 필드를 통해 이미지를 입력하고, 관심 종목의 경우 임의로 몇개를 설정해서 여러가지를 선택할 수 있게 multiplechoicefield를 사용하였습니다.

F 502: 가입 페이지에서 여러 정보를 입력받아 저장하고, 회원가입이 끝나면 별도의 로그인 과정 없이 바로 서비스 이용이 가능하도록 자동 로그인 기능을 구현했습니다.

F 503: 로그인 폼을 통해 인증에 성공하면 메인 페이지로 이동하게 했고, 잘못된 정보 입력 시 안내 메시지가 나오도록 처리했습니다.

F 504: 로그아웃 URL을 설정해 세션을 안전하게 종료하고, 로그아웃 후에는 다시 메인 페이지로 리다이렉트되도록 구성했습니다.

F 505: 비밀번호 변경 전용 페이지를 만들고, 입력 오류나 비밀번호 불일치 시 사용자가 이해하기 쉽게 한글로 에러 메시지를 띄우도록 설정했습니다.

F 506: 게시글 작성 시 작성자의 username이 자동으로 저장되게 했고, 본인의 글이 아닐 경우 수정이나 삭제를 할 수 없도록 철저하게 권한을 체크했습니다.

F 507: 프로필 화면에서 유저의 개인 정보뿐만 아니라 그동안 작성했던 게시글 목록을 한눈에 모아볼 수 있도록 구성했습니다.

F 511: 사용자가 커뮤니티에 남긴 글들을 바탕으로 LLM으로 분석하여, 어떤 투자 스타일을 가졌는지를 제공하는 심화 기능을 구현했습니다.

프로젝트 소감

박민규: 장고의 `AbstractUser`를 활용해 유저 모델을 처음부터 커스터마이징해 본 것이 가장 기억에 남고, 특히 LLM을 연동해 투자 성향을 분석하는 기능을 구현했을 때의 성취감이 정말 컸습니다. 초반에는 유저 모델이나 게시글 권한 설정이 복잡해서 많이 헷갈렸지만, 문제를 하나씩 해결해 나가는 과정에서 장고의 MVT 패턴과 데이터 흐름을 깊이 있게 이해할 수 있었던 아주 뜻깊은 프로젝트였습니다.

장민석: 수업시간에 배운 내용들을 바탕으로 따라서 진행하다보니 생각보다 수월하였습니다. 이제 실제 웹페이지와 같이 로그인, 로그아웃, 회원가입 등을 구성할 수 있고 비밀번호의 경우 암호화 시켜서 할 수 있게 구현하였으며, 자잘한 사용자 편의성을 위한 구성을 하려고 노력하였습니다. 장고를 활용하여 클래스와 기본 메서드 및 폼을 이용하여 다양한 것들을 구성할 수 있었습니다. 여기에 저번에 배운 html 스타일을 바꿀 수 있다면 더욱 완벽한 페이지가 될 것 같지만 그 부분에서 조금 부족하다고 느꼈습니다.
