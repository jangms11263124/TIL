# pjt06

## 소감

#### 장민석: 전에 프로젝트에서는 api key를 통해 open_api 데이터를 받아오는 것을 배웠다면 이번에는 직접 크롤링을 통해 데이터를 불러오는 방법을 배웠습니다. 관리자 도구를 통해 원하는 사이트를 직접 검색하지 않고 코드를 통해 자동으로 불러와서 그 데이터를 가지고 LLM을 이용하여 전처리 과정을 거치고 증강도 하여 3가지의 데이터를 얻고 최종적으로 txt파일로 저장하게 하였습니다. 그 과정에서 selenium과 전에 배운 langchain, pandas를 사용하였습니다. 향후 종목만 바꾸는 것이 아니라 다른 사이트에서도 원하는 데이터를 크롤링하여 향후 프로젝트에 사용하고자 합니다. 그리고 그 데이터를 가지고 지금까지 배운 Django, html을 통해 실제로 사용자들이 보기 좋은 사이트를 만들고자 합니다.



#### 박민규: 삼성전자에 대한 시장 여론을 파악하기 위해 토스 증권 커뮤니티의 댓글 수집 프로젝트를 진행했습니다. Selenium으로 동적 페이지를 크롤링하는 법을 익혔으며, LLM을 활용해 부적절한 댓글을 필터링하고 데이터 증강을 통해 분석용 데이터셋을 확장하는 과정을 경험했습니다. 마지막으로 정제된 데이터를 .txt 파일로 저장하며 마무리했습니다. 이번 기회를 통해 실시간 데이터를 직접 수집하고 가공하는 역량을 쌓았으며, 향후 정보가 필요할 때 유용하게 활용할 수 있을 것으로 기대합니다.
