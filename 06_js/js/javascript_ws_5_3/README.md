학습주제
비동기 자바스크립트와 axios


학습목표
Ajax 기술을 이해하고 axios를 활용해 API 서버로 HTTP 요청을 보낼 수 있다.
주어진 요구사항에 따라 axios 라이브러리를 작성하고 활용할 수 있다.


문제의도
자바스크립트로 클라이언트와 서버간의 네트워크 요청에 대한 이해도를 평가한다.
axios를 활용해 서버로부터 데이터를 받아 DOM을 조작하는 것에 대한 능력을 검증한다.

문제
axios와 TMDB API를 활용하여 인기 영화 목록을 실시간으로 받아올 수 있는 어플리케이션을 제작하고자 한다. 
Get Popular 페이지의 가이드 대로 현재 인기있는 영화들의 정보를 axios 로 받아오고, 다음 예시 화면과 같이 평점이 7점 이상인 영화의 정보를 리스트로 나타내시오.
요구사항
  참고 문서 : https://www.themoviedb.org/

API Key 발급
계정이 없다면 회원가입을 먼저 진행한다.
단, 회원 가입시 인증 이메일 전송에 시간이 소요 될 수 있으므로 다른 작업을 우선 진행하여도 좋다.
메일 전송이 너무 늦어진다면, 재전송 링크를 클릭하거나 스팸 메일함을 확인한다.

회원 가입 후, API KEY를 발급 받는다.
프로필 수정 → 설정 → API 에서 발급 가능
진행 과정은 제공된 TMDB_API_images 폴더를 참고.

GET Popular 요청 방법 확인
APIDOCS : https://developers.themoviedb.org/3/
좌측 상단 API Reference 탭 이동 > popular 검색
요청 필요 정보 확인

GET 요청 실행
언어 : 한국어
페이지 : 1
응답 받은 모든 영화들 중, vote_average 값이 7이상인 경우만 배열에 추가

화면 구성
구성이 완료된 배열을 순회하여 모든 정보를 화면에 렌더링

단, 평점은 주기적으로 변경 될 수 있으므로 실행 결과 예시와 다를 수 있음에 유의
