비동기 자바스크립트와 axios


학습목표
Ajax 기술을 이해하고 axios를 활용해 API 서버로 HTTP 요청을 보낼 수 있다.
주어진 요구사항에 따라 axios 라이브러리를 작성하고 활용할 수 있다.


문제의도
자바스크립트로 클라이언트와 서버간의 네트워크 요청에 대한 이해도를 평가한다.
axios를 활용해 서버로부터 데이터를 받아 DOM을 조작하는 것에 대한 능력을 검증한다.

문제
강아지 사진 어플리케이션의 심화 과정을 제작하고자 한다. 
최초로 페이지가 렌더링 될 때는, axios로 얻어온 강아지 사진이 없으므로 기본으로 제공된 이미지를 화면에 렌더링 한다.
이후, axios로 get요청을 보내 얻은 강아지 사진으로 변경하는 코드를 작성한다. 이미지를 얻고 난 후에는 h2태그는 제거되어야 한다. 
요구 사항을 만족하는 코드를 작성하시오.
