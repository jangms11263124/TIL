학습주제
Ajax를 사용한 클라이언트와 서버 간의 비동기 통신

학습목표
Ajax를 사용하여 클라이언트와 서버 간의 비동기 통신을 구현하는 방법 이해 
axios를 활용하여 JavaScript에서 HTTP 요청을 보내는 방법 습득 
Django 서버에서 axios로 보낸 요청을 처리하고 응답하는 방법 익힘

문제의도
Ajax를 활용하여 클라이언트와 서버 간의 상호작용을 구현하는 방법을 학습한다. 
axios를 사용하여 클라이언트에서 HTTP 요청을 보내고 서버에서 응답을 처리하는 과정을 익힌다. 
Django에서 axios로 보낸 요청을 받아 처리하고, 적절한 응답을 보내는 방법을 익힌다.
문제
스켈레톤 파일을 활용하여 구현된 게시글 삭제 기능을 javascript 를 통해 요청할 수 있도록 요구사항에 맞는 코드를 작성하시오.
요구사항
 delete form 태그 수정
요청 수행을 axios 로 변경하며 더 이상 필요 없어진 html 속성들은 제거한다.
form 태그 요소를 javascript 로 선택할 수 있도록 id 속성을 추가한다.
id는 'delete-form'으로 작성한다.

게시글 삭제 요청을 위해 필요한 요소를 선택하고 이벤트 핸들러를 할당하시오.
querySelector 를 사용해 '#delete-form' id 속성을 가진 요소를 선택한다.
form 요소에 이벤트 핸들러를 할당하고, 'submit'의 기본동작을 취소한다.

기능 동작 확인
console.log('게시글 삭제 버튼 클릭!')을 출력하여 form의 기본 동작을 취소하고 있는지 확인하시오.
DELETE 버튼(input:submit) 클릭 시 더 이상 기능이 작동하지 않고, 개발자 도구 콘솔 창에 의도대로 '게시글 삭제 버튼 클릭'이 출력되는지 확인한다.

기능 확인
삭제 버튼 클릭 시 javascript 의 confirm() 메서드를 통해 삭제 요청에 대한 동의 여부를 재확인 합니다.
예시) if (confirm('정말 삭제하시겠습니까?')) {}
Ajax를 통해 삭제 요청을 수행할 수 있도록 코드를 작성한 뒤 정상적으로 게시글 삭제 요청이 수행되는지 확인하시오.
삭제 동작이 완료 된 후 현재 브라우저의 URL을 /articles/ 로 이동시킵니다.
예시) location.href = '/articles/'
