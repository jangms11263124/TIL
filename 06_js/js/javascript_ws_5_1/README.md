학습주제
비동기 자바스크립트와 axios


학습목표
Ajax 기술을 이해하고 axios를 활용해 API 서버로 HTTP 요청을 보낼 수 있다. 
주어진 요구사항에 따라 axios 라이브러리를 작성하고 활용할 수 있다.


문제의도
자바스크립트로 클라이언트와 서버간의 네트워크 요청에 대한 이해도를 평가한다. 
axios를 활용해 서버로부터 데이터를 받아 DOM을 조작하는 것에 대한 능력을 검증한다.

문제
공유된 HTML 코드의 주석과 마크업을 참고하여, 버튼을 클릭하면 axios를 통해 API 요청을 보내고 받아 온 이미지 데이터를 페이지에 렌더링하는 앱을 완성하시오.
요구사항
  참고 문서 : https:/dog.ceo/

axios를 사용하여 API_URI로 GET 요청을 보낸다.
.then 메서드를 통해 요청이 성공적인 경우의 콜백함수를 정의한다.
응답객체의 데이터에서 이미지에 대한 리소스를 img 요소의 src 속성으로 할당한다.
새 img 태그를 생성하지 않는다.
기존의 img 태그의 src 속성만 변경한다.
