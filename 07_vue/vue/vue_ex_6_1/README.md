Routing
네트워크에서 경로를 선택하는 프로세스로 웹 어플리케이션에서 다른 페이지 간의 전환과 경로를 관리하는 기술입니다.
SPA에서 routing은 브라우저의 클라이언트 측에서 수행하며, 클라이언트 측 JavaScript가 새 데이터를 동적으로 가져와 전체 페이지를 다시 로드하지 않습니다.페이지는 1개이지만, 링크에 따라 여러 컴포넌트를 렌더링하여 마치 여러 페이지를 사용하는 것처럼 보이도록 해야 합니다.

학습 문제

개발자 Alan은 커뮤니티 게시판에 들어갈 프로필 페이지를 개발하고자 한다. 크게 3개의 페이지로 구성하고, 특히 프로필 페이지 안에서는 사용자의 상세 정보와 사용자가 작성한 게시글을 출력할 수 있도록 만들 예정이다. 첫 번째 단계로 메인 페이지와 소개 페이지를 간단히 만들기로 했다. 요구 사항에 맞게 애플리케이션을 작성하시오.
제공된 스켈레톤 프로젝트에서 진행한다.
HomeView 컴포넌트를 생성한다.
src/views 폴더 내에 위치한다.
router의 주소 '/'에 매핑되며 주소 이름은 'home'이다.
AboutView 컴포넌트를 생성한다.
src/views 폴더 내에 위치한다.
router의 주소 '/about'에 매핑되며 주소 이름은 'about'이다.
App 컴포넌트에 HomeView와 AboutView 컴포넌트를 렌더링 한다.
RouterLink를 사용해 두 컴포넌트에 대한 HTML a요소를 생성한다.
 Named Routes 개념을 사용해 경로에 대한 주소가 아닌 주소의 이름을 활용한다.
 RouterView를 사용해 컴포넌트를 표시하는 위치를 지정한다.
