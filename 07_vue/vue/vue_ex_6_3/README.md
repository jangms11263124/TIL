Vue Router의 중첩 라우팅, 데이터 전달 방법에 대한 이해와 적용


학습 목표
Vue Router를 사용하여 중첩된 라우팅을 설정하는 방법 이해
중첩된 라우팅을 통해 프로필 페이지 내의 하위 페이지를 구성하는 방법 습득
중첩된 라우트를 통해 복잡한 페이지 구조를 관리하고 사용자 경로를 쉽게 탐색할 수 있는 경험을 습득


학습 개념

매개 변수를 사용한 동적 경로 매칭
주어진 패턴 경로를 동일한 컴포넌트에 매핑 해야 하는 경우 활용할 수 있습니다.
ex) user/1user/2user/3
위와 같이 일정한 패턴의 URL 작성을 반복해야 하는 경우에 특히 유용합니다.
1.	routes 등록 시, path에 매개변수 넣기(매개변수는 콜론(:)으로 표기)

2.	Vue 컴포넌트에서 매개 변수 가져오기

문제
학습 문제

Alan은 마지막 단계로 프로필 페이지 내부에서 기능을 더 업그레이드하려고 한다. 첫 번째로 프로필 페이지에서 ‘상세 프로필’ 링크를 누르면 사용자의 추가 정보를 보여줄 것이다. 두 번째로 ‘작성한 게시글’ 링크를 누르면 사용자가 작성한 게시 글 목록을 출력할 것이다. 그런데 출력된 게시글 목록의 각 제목을 클릭하면, 클릭한 게시 글의 나머지 상세정보까지 출력하고자 한다.Alan은 이 모든 것을 페이지 전환 없이 오로지 프로필 페이지에서 구현하는 것이 목표이다. 
요구 사항에 맞게 애플리케이션을 작성하시오.
이전 문제 '동적 라우팅, 네비게이션 가드 연습하기'에서 풀이한 프로젝트 또는 제공된 스켈레톤 프로젝트에서 진행한다.
Profile 컴포넌트
사용자의 상세 프로필 정보를 담당한다.
UserView 컴포넌트의 RouterView에서 렌더링 되는 중첩된 컴포넌트이다.
src/components 폴더 내에 위치한다.
Profile의 주소는 UserView 컴포넌트 주소의 하위 주소이다.
router의 주소 '/user/:username/profile'에 매핑되며 주소 이름은 'user-profile'이다.
PostList 컴포넌트
사용자가 작성한 게시글 출력을 담당한다. (실제로 사용자가 작성하는 것은 아니다.)
 반응형 변수 posts는 임의의 게시글 배열을 나타낸다.
 배열 posts는 객체 3개를 가지며 각 객체의 속성은 id, title, content로 구성되어 있다.
 배열 posts는 하위 컴포넌트 PostListItem를 순회하며 props로 전달된다.
UserView 컴포넌트의 RouterView에서 렌더링 되는 중첩된 컴포넌트이다.
src/components 폴더 내에 위치한다.
PostList의 주소는 UserView 컴포넌트 주소의 하위 주소이다.
router의 주소 '/user/:username/posts'에 매핑되며 주소 이름은 'user-posts'이다.
PostListItem 컴포넌트
PostList 컴포넌트의 하위 컴포넌트이다.
PostList 컴포넌트로 전달받은 게시글 출력을 담당한다.
PostDetail 컴포넌트
각 게시글의 상세 정보를 담당한다.
PostList 컴포넌트의 RouterView에서 렌더링 되는 중첩된 컴포넌트이다.
src/components 폴더 내에 위치한다.
PostDetail의 주소는 PostList 컴포넌트 주소의 하위 주소이다.
router의 주소 '/user/:username/posts/:id'에 매핑되며 주소 이름은 'post-detail'이다.
PostList 컴포넌트의 동일한 반응형 변수 posts를 선언한다. (직접 동일하게 작성한다.)
PostListItem 컴포넌트에서 출력되고 있는 각 게시글의 제목을 링크를 클릭하면 목록 하단에 렌더링 된다.
선택한 게시글의 id, title, content를 출력한다.
배열 posts를 활용해 어떤 게시글이 선택되었는지 선별한다.
선택하는 게시글에 따라 템플릿에 렌더링 되는 게시글의 상세 정보와 URL이 함께 변경되어야 한다.
URL 예시) /user/admin/posts/1 <-> /user/admin/posts/2
내비게이션 가드를 참고한다.
