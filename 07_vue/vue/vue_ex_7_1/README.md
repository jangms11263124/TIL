학습 주제
Pinia를 사용한 Vue 애플리케이션의 상태 관리와 상태 공유 방법에 대한 학습


학습 목표
Pinia를 사용하여 상태 관리를 구성하는 방법 이해
초기 저장소를 설정하고 필요한 데이터를 저장하고 관리하는 방법 습득
저장소에서 데이터를 가져와 Vue 컴포넌트에 출력하는 방법 익힘


학습 개념

Pinia
Vue 컴포넌트는 여러 뷰가 동일한 상태에 종속되거나 서로 다른 뷰의 기능이 동일한 상태를 변경시켜야 하는 경우에 상태 관리의 단순성이 무너질 수 있습니다.
이 때 해결책 중 하나는 각 컴포넌트의 공유 상태를 추출하여, 전역에서 참조할 수 있는 저장소에서 관리하는 것입니다. 바로 해당 기술이 Pinia입니다.
Pinia 사용 예시

1.	stores/*.js 에 필요한 상태를 정의하기- defineStore 메서드를 호출하며, 필요한 상태를 저장합니다.


2.	필요한 컴포넌트에서 상태 불러오기- store 객체를 가져온 뒤, 그 속에 정의한 상태를 가져옵니다.


학습 방향
문제
학습 문제

개발자 Ben은 소규모 온라인 상점을 운영하는 개발자로서, 최근 상품 관리 및 재고 관리에 어려움을 겪고 있다.고객들의 주문이 많아지면서 상품 재고를 효율적으로 관리하고 주문에 대한 신속한 처리가 필요해졌다. 우선 Ben은 현재 상점에서 보유하고 있는 모든 상품을 한데 모아 재고를 확인하고자 한다.요구 사항에 맞게 애플리케이션을 작성하시오.
제공된 스켈레톤 프로젝트에서 진행한다.
'useProductStore' store
현재 프로젝트의 store이다.
useProductStore에 상품 목록을 나타내는 'products' state를 정의한다.
products의 데이터 타입은 배열이며 3개의 상품 데이터를 가지고 있다.
 각 상품 데이터의 데이터 타입은 객체이다.
 각 객체의 구성요소는 id, title, body로 구성되어 있다.
ProductList 컴포넌트
App 컴포넌트의 하위 컴포넌트이다.
src/components 폴더 내에 위치한다.
useProductStore에 있는 'products' state를 출력한다
