생성한 컴포넌트를 메인 애플리케이션 파일에 등록하여 화면에 렌더링


학습 개념

Bootstrap이란?
웹사이트를 쉽게 만들 수 있도록 도와주는 HTML, CSS, JS 프레임워크 중 하나로 반응형 페이지도 Bootstrap을 사용한다면 손쉽게 작동시킬 수 있습니다. 
Vite 프로젝트에 Bootstrap CDN 적용하기
https://getbootstrap.kr/ 에 접속합니다.
메인 페이지 우측 하단, CDN으로 포함시키기로 이동합니다.
<link> 태그와 <script> 태그를 복사하여 Vite 프로젝트의 index.html 파일 내 적절한 위치에 선언합니다.

문제
학습 문제

기본 컴포넌트 구조 배치를 마친 Emily는 본격적으로 Bootstrap의 도움을 받아 스타일링 및 반응형 레이아웃을 설정하고자 한다.요구 사항에 맞게 애플리케이션을 작성하시오.
"Bootstrap을 활용한 컴포넌트 레이아웃 구성"- 이전 문제 'Vite를 이용한 프로젝트 생성 연습하기'에서 풀이한 프로젝트 또는 제공된 스켈레톤 프로젝트를 사용한다.
Bootstrap을 사용한다.
index.html의 적절한 위치에 Bootstrap CDN을 작성한다.
MyComponent의 header 요소는 페이지의 제목이 출력된다.
항상 페이지 상단에 고정된다.
제목 텍스트는 상하좌우 가운데 정렬된다.
MyComponent의 main 요소는 메인 갤러리 영역이다.
Bootstrap Card 컴포넌트가 4개 사용된다.
Card는 정수 4 값을 가지는 반응형 변수 'numberOfItems' 와 v-for를 활용해 출력된다.
각 Card의 이미지는 assets/ 폴더에 위치한 sample 이미지를 사용한다.
Card는 화면 너비에 따라 반응형 레이아웃을 가진다.
화면 너비가 576 미만이면 한 행에 1개씩 출력된다.
화면 너비가 576 이상이면 한 행에 2개씩 출력된다.
화면 너비가 768 이상이면 한 행에 3개씩 출력된다.
요구사항 외 스타일링은 실행결과를 참고해 자유롭게 구성한다.
