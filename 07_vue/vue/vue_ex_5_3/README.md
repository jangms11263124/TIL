목표
학습 주제
Props와 emit event를 활용한 컴포넌트 간 데이터 흐름 관리


학습 목표
Props를 사용하여 데이터를 하위 컴포넌트로 전달하는 방법 이해
컴포넌트 이벤트를 발생시켜 부모 컴포넌트로 이벤트를 전달하는 방법 이해
Props 및 이벤트를 활용하여 Vue 애플리케이션에서 유연한 데이터 흐름을 구축하는 방법 습득


학습 개념
•	$emit()자식 컴포넌트가 이벤트를 발생시켜 부모 컴포넌트로 데이터를 전달하는 역할의 메서드입니다.(‘$’ 표기는 Vue 인스턴스나 컴포넌트 내에서 제공되는 전역 속성이나 메서드를 식별하기 위한 접두어)
자식 컴포넌트에서 정의한 emit 메서드에 의해 이벤트가 발생하면, 부모 컴포넌트에서 v-on을 통해 해당 이벤트를 감지하여 콜백 함수를 수행할 수 있습니다.(단, 선언 및 발신 시 camelCase, 부모 컴포넌트에서 수신 시 kebas-case로 선언합니다)
자식 컴포넌트에서 emit 메서드 등록하기(메서드 발신 시에는 camel case로 등록하기)
<!-- ParentChild.vue -- >

<script setup>
const emit = defineEmits(['someEvent'])

const buttonClick = function () {
emit('someEvent')

</script>

<!-- ParentChild. vue -- >
<button @click="buttonClick">클릭</button>

자식 컴포넌트에서 발신한 이벤트를 부모 컴포넌트에서 수신하기(이벤트 수신 시에는 kebab case로 작성하기)
<! -- Parent.vue -- >
<ParentChild @some-event="someCallback"/>

학습 방향
문제
학습 문제

Maria는 애플리케이션의 컴포넌트 구조를 재구성하는 것에 성공했다. 마지막으로 선택한 상품을 장바구니에 추가 및 삭제할 수 있도록 기능을 추가하려고 한다. 요구 사항에 맞게 애플리케이션을 작성하시오.
이전 문제 'Props 컴포넌트 구조화 연습하기'에서 풀이한 프로젝트 또는 제공된 스켈레톤 프로젝트에서 진행한다.
Cart 컴포넌트
App 컴포넌트의 하위 컴포넌트이다.
장바구니에 추가된 제품이 출력되는 영역이다.
장바구니에 담긴 제품이 없다면 아무것도 출력하지 않는다.
App 컴포넌트로부터 장바구니 제품 목록에 대한 데이터를 props로 전달받는다.
장바구니에 담긴 제품의 이름, 가격 그리고 장바구니 목록에서 제거할 수 있는 삭제 버튼을 출력한다.
장바구니 제품 추가 기능
ProductListItem 컴포넌트의 '장바구니 추가' 버튼을 클릭하면 emit 이벤트가 호출된다.
호출된 emit 이벤트는 ProductList 컴포넌트를 거쳐 App 컴포넌트가 청취할 수 있어야 한다.
App 컴포넌트가 청취하면 장바구니 목록 변수에 선택된 제품을 추가한다.
추가된 제품은 Cart 컴포넌트에 실시간으로 출력되어야 한다.
장바구니 제품 삭제 기능
Cart 컴포넌트의 '삭제' 버튼을 클릭하면 emit 이벤트가 호출된다.
호출된 emit 이벤트를 App 컴포넌트가 청취한다.
App 컴포넌트가 청취하면 장바구니 목록 변수에서 선택된 제품을 삭제한다.
장바구니 제품의 총 가격 계산
장바구니 제품의 총가격을 나타내는 반응형 변수는 App 컴포넌트에 위치한다.
장바구니 제품 목록에 담긴 모든 제품의 계산된 총합을 반환하여 적절한 위치에 출력한다.
해당 변수는 장바구니 제품 목록에 변화가 있을 때만 재연산 된다.
